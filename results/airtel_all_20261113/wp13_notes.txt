WP13: Defence simulations.

All results in wp13_defence_simulations.csv are SIMULATED.
Defences are applied by perturbing the already-extracted feature vectors
(pkt_* sizes, timing, counts) — not by replaying or modifying PCAPs.

Defences:
  no_defence       : baseline (unmodified)
  pad_constant_64  : round each pkt to next multiple of 64 bytes
  pad_constant_128 : round each pkt to next multiple of 128 bytes
  pad_random_128   : add uniform random noise U[0,128] per packet
  jitter_50ms      : add U[0,50ms] jitter to IAT features
  jitter_200ms     : add U[0,200ms] jitter to IAT features
  cover_10pkts     : inject 10 dummy 500-byte packets per flow
  cover_50pkts     : inject 50 dummy 500-byte packets per flow
